# /feature

1. **Arquitecto:** Explora el código y genera la Spec Unificada (Alcance, Contratos y Checklist TDD).
2. **Revisión Humana:** Presenta la Spec al usuario y espera aprobación explícita.
3. **Obrero (Builder):** Implementa siguiendo TDD estricto (RED -> GREEN -> REFACTOR).
4. **Verificación Determinista:** Ejecuta `gentle-ai test` en la terminal local hasta exit code 0.
